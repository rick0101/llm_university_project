  "methodology": "The authors propose an adaptive attack framework to evaluate the robustness of defenses against Indirect Prompt Injection (IPI) in LLM agents. In an IPI attack, an adversary embeds malicious instructions into external data sources. The adaptive attack assumes white-box access and inserts an optimized adversarial string (prefix or suffix) into the external content. The core optimization relies on the Greedy Coordinate Gradient (GCG) algorithm, adapted to maximize the probability of the LLM generating a specific target response (e.g., a ReAct thought process or a JSON function call) that executes the attacker's tool. To bypass specific defenses, the authors introduce specialized variants: Multi-objective GCG (M-GCG) adds a stealth objective to evade detection-based defenses (jointly or iteratively optimizing to misclassify the attack as benign); Two-stage GCG (T-GCG) targets paraphrasing defenses by training a two-part string where the paraphraser's output matches the target trigger; and AutoDAN generates semantically meaningful adversarial strings to bypass Perplexity Filtering (PF). The authors evaluate eight defenses categorized into detection-based (Fine-tuned Detector, LLM-based Detector, Perplexity Filtering), input-level (Instructional Prevention, Data Prompt Isolation, Sandwich Prevention), and model-level (Adversarial Finetuning).",
