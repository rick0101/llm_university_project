# Code Package for VARK: Disentangling Prompt-Based Safety from Algorithmic Resilience in Large Language Models

## Description
This directory contains the experiment project used for the paper.

## Project Files
- `config.py`
- `data_utils.py`
- `engine.py`
- `main.py`
- `model_zoo.py`

## How to Run
`python main.py`

## Dependencies
Install dependencies with `pip install -r requirements.txt` if needed.
